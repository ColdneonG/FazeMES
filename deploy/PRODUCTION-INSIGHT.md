# 生产决策中心

访问 `http://127.0.0.1:5173/mes/insight`，或从 MES 工作台右上角进入。

以下命令在仓库根目录通过 PowerShell 7 执行，Java、Maven 的选择遵循项目 README 的环境要求。

## 六项功能

| 功能 | 使用方式与依据 |
| --- | --- |
| 交期风险 | 检查未结工单的排产完整性、交期、逐单物料缺口、未处置安灯、待完成过程检验及关联设备状态。展开工单可查看任务和物料依据。资料不足时显示未知交期。 |
| 插单与排产仿真 | 选择工单，比较正常队列、工单优先、优先并延长日工时三种方案，查看工单影响、资源排队与加班成本。未排产的工单可指定一个工作站及假设加工工时；不会创建真实任务。 |
| 质量关联 | 按工作站、工序、产品、生产批次与任务 SOP 版本分组，比较同产品不良率基线。可调时间范围及样本门槛，展开查看完成报工原始记录。关联差异需现场核实。 |
| 异常闭环 | 可从交期风险建立跟进、导入未处置安灯或直接建立异常。分配负责人和处理截止日期，记录确认原因、措施与验证证据，保留全部处理履历。 |
| 实时业务助手 | 查询当前交期、缺料、异常、质量和流程数据，支持具体工单编码。默认使用明确标识的业务规则答复，无需模型；可选复用现有模型配置进行分析。建议可编辑保存为草稿，再确认转为异常跟进。 |
| 流程瓶颈 | 查看计划启动至首次完成报工的日历间隔中位数、未完成任务数、实际报工工序路径和工单事件履历。分批报工不会直接标为返工。 |

异常状态为：待处理 → 处理中 → 待验证 → 已关闭。进入验证须填写确认原因和措施，关闭须填写验证通过的证据。验证失败或复发可返回处理中；关联安灯在验证关闭后处置，由本闭环关闭的安灯在重新处理时恢复未处置。并发编辑通过版本检查防止覆盖。

## 计算范围

- 排产按每工作站一个资源、工单工序串行计算，任务时长每工作日折合8小时；周一至周五08:00开始，日工时8至12小时。
- 缺料、待检和设备恢复时间没有可用的确定承诺时，仅列出风险；不虚构解除时间。排产未计换型、人员技能、法定节假日及复杂并行工艺，结果用于方案评审。
- 额外成本按各工作站在周一至周五16:00至当日排班结束之间的实际加工小时合计，乘输入的小时成本计算；排班结束为08:00加日工作时长，跨夜与周末的闲置时间不计费。多站同时加工分别累计资源小时，不等同于完整制造成本。
- 齐套分析逐单读取当前库存和预占，未同时分配多工单物料；仿真不写排产、不分配库存。
- 单次最多分析300张未结工单、1500个未结任务；质量与路径分析最多5000张报工，超限时提示缩小范围。
- 质量门槛同时要求至少两张报工以及输入的样本数量。同产品分别比较，避免混合不同产品。不良率使用完成报工的不良数量，不推断未记录的参数或设备实际使用情况。
- 流程间隔来自计划和完成报工事件，不等同于真实设备待机时间。
- 模型分析需具备原 AI 助手会话权限并配置模型；发送前按模型上下文预算检查业务摘要。模型文本不直接执行 SQL、排产或库存操作。

现有演示库只有一张草稿工单、没有完成报工，因此质量和流程页初次打开显示空数据是正常情况。维护真实任务和完成报工后会自动参与分析。

## 权限与更新

新增 `mes:insight:query`（查询）、`mes:insight:simulate`（仿真）、`mes:insight:manage`（异常与草稿管理）、`mes:insight:chat`（业务问答）。默认授予本机示例租户的管理员角色；普通角色需按业务授权。所有查询、写入、关联资料和处理履历按租户隔离；建议草稿仅其创建人可见和转换。

新表与菜单迁移位于 `database/migrations/20261019_production_insight.sql`，通过现有增量迁移脚本应用。

修改后端后，保持现有 MySQL/Redis 运行，使用仅重启后端的脚本：

```powershell
pwsh -NoProfile -File deploy/restart-backend.ps1 -Build
```

该脚本先校验环境并备份旧 JAR 到 `.runtime/backups/yudao-server.previous.jar`，再停止受管理后端、执行待应用迁移并构建，避免旧代码在质量核查期间继续写入以及 Windows 对运行中 JAR 的文件锁。迁移或构建失败时后端保持停止，修复后重试；恢复旧 JAR 前须确认它兼容已应用迁移。数据库不会被停止，也不导入初始化 SQL。前端代码通过当前 Vite 服务热更新。

## 验证

- 新增7项后端测试：工作日历、工位排他、工序先后、优先工单影响、加班工时、异常状态门槛、处理履历、关联安灯、租户隔离、草稿归属与幂等、多用户并发覆盖。
- 新功能28项真实 HTTP 检查：`deploy/verify-production-insight.py`。脚本仅创建明确标记的临时分析样本，并在结束时按其精确主键清理，不改变现有工单和库存。
- 原有97个MES列表接口与本地附件上传下载验证通过。
- 全量 Vue/TypeScript 类型检查、新增页面 ESLint、Stylelint 及 Vue 模板编译检查通过。
- 浏览器验证：风险页面、三方案仿真、质量空数据、异常建立表单、业务问答、业务依据表格、草稿编辑表单及流程页。

验证报告位于运行副本的 `.runtime/production-insight-verification.json` 和 `.runtime/local-verification.json`。
