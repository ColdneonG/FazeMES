# Agent 业务使用说明

入口为“AI助手与知识库 → 业务 Agent”，也可进入“生产决策中心 → 业务助手”。知识助手保留发布文档问答；业务 Agent 直接查询当前租户的业务记录。

## 可以直接尝试

- `查询全部未完成工单列表`：实际工单、产品、数量、状态及需求日期。
- `生成本月未完成工单报表`：按工单创建日期筛选，下载本次查询的 Excel 快照。
- `生成2026-10-01至2026-10-24工单报表`：起止日期均包含在范围内。也支持完整工单或产品编码。
- `查询设备状态`：设备台账中的登记状态，不冒充实时采集信号。
- `新建异常：WO-001 缺料需要跟进`：核对或修改标题、分类、真实工单编码及负责人，生成预览，再确认执行。
- `将异常 #123 标记为处理中`：核对编号、负责人及说明，再确认执行；后续可进入待验证、已关闭。验证和关闭需补齐真实原因、措施及验证证据，遵守正常状态流转。

已有的库存月度台账、单据库存流水、交期、缺料、成本查询继续可用。勾选“使用已配置模型辅助理解”可让模型在已开放的工具中选择能力；业务 SQL、库存计算、权限和实际写入由后端决定。未开放的采购下单、库存过账、工单增删等操作不会因模型生成文字而执行。

## 执行与权限

查询需要业务助手权限和对应模块查询权限；导出还需要工单导出权限；异常操作需要异常管理权限。后端每次重新校验当前登录人、租户和权限。预览绑定当前用户及会话回合，15 分钟有效；修改后旧预览作废。

确认请求只携带预览编号和一次确认凭据，执行内容取自服务端已核对快照。执行调用现有异常闭环业务服务，实际写入、事件历史和成功回执在同一事务中保存。网络超时可重试同一次确认，不重复创建记录。重新打开会话仍能看到执行回执；同一轮成功后不能再次创建。

报表保留查询时的完整数据快照，下载不会按当前新数据重新计算。页面按 20 条显示，导出包含全部匹配记录；超过 5000 张工单须补充范围，防止大范围查询耗尽资源。日期过滤基于工单创建日期。零记录明确显示空结果。

## 模型调用

本项目不再设置模型计费、累计 Token、日/月次数、分钟频率或并发配额，删除了对应运行服务、接口和“用量与预算”界面。历史计量表和历史增量迁移保留以便追溯，不再拦截任何调用，也不继续计量。

模型服务商的账单、余额、速率、区域可用性仍由服务商控制。每次请求仍保留模型上下文长度、输出长度、超时、服务地址及凭据保护。规则业务查询及已确认的异常操作无需调用外部模型。

新增增量迁移 `20261024_agent_business_actions.sql` 保存业务操作预览和执行回执。升级前备份数据库，使用 `deploy/start-local.ps1 -Build` 应用迁移并重启；已有数据库不会重新导入示例数据。
